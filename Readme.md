# DevOps Troubleshooting Lab

A hands-on collection of Linux, Docker, Kubernetes, CI/CD,
networking and infrastructure troubleshooting exercises.

The goal of this repository is to practice diagnosing realistic
DevOps/SRE incidents rather than only learning commands.

## Topics

- Linux troubleshooting
- Networking
- Docker
- Kubernetes
- CI/CD
- Terraform
- Observability
